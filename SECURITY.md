# Security policy

## Supported versions

Security fixes are applied to the latest release and the `main` branch.

| Version | Supported |
|---|---|
| 1.1.0 | Yes |

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. Use GitHub's
private vulnerability reporting feature when available, or email
`ahiri.adil@gmail.com` with:

- the affected version or commit;
- reproduction steps or a proof of concept;
- the expected impact;
- any suggested mitigation.

Receipt will normally be acknowledged within seven days. A validated issue will
be coordinated privately until a fix and release note are ready.

NucleoScan processes local scientific files and may download public PDB or
UniProt records. Users should review untrusted input files and run the software
with the minimum required filesystem permissions.
